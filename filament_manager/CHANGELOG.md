# 更新日志

## [1.0.0] - 2024-03-10

### 新增
- 耗材类型管理（预设+自定义）
- 耗材卷管理（添加、编辑、删除）
- 自动编号（同类型下递增）
- 剩余克数统计
- 手动变更剩余量
- 使用历史记录
- 剩余量预警（<10g）
- 绿白配色主题（Bambu Studio风格）
- 搜索功能
- 云端同步字段预留

### 预设类型
- 30+常见耗材类型
- 支持Bambu Lab、Creality、eSun等主流品牌
- 支持PLA、PETG等常见材质

### 技术栈
- Flutter 3.19
- SQLite数据库
- Windows和Android平台支持
- GitHub Actions自动构建
